# Snipcast

Кросс-платформенное приложение для вставки текстовых шаблонов (macOS и Windows). Поддерживает различные группы шаблонов, возможность использовать переменные в тексте и редактируемые части сообщений перед отправкой.

## Требования

- [Rust](https://www.rust-lang.org/tools/install) (stable)
- Node.js 18+

## Запуск

```bash
cd /path/to/Snipcast
npm install
npm run tauri dev
```

Сборка установщика:

```bash
npm run tauri build
```

## Внешний HTTP API

Скриншоты можно снимать из скриптов через локальный HTTP API (`POST /capture`,
`POST /preset`, `GET /health`). Включается в настройках приложения.

Полная инструкция: [docs/api.md](docs/api.md).

## Захват в 0.35.0

Выделение продолжается между экранами. После выбора области: C копирует
с аннотациями и закрывает захват; Enter открывает «Сохранить как». Клавиши
1–5 выбирают стрелку, линию, фигуру, свободное рисование и текст.
Стрелки перемещают курсор на один физический пиксель.

Shift выравнивает линию, стрелку и текущий штрих по горизонтали или вертикали.
Ctrl+Z отменяет действие, Ctrl+Y / Ctrl+Shift+Z возвращают его. В поле текста
Enter переносит строку, Ctrl+Enter завершает ввод.

«Сумма» складывает распознанные числа и копирует результат. Обновления
проверяются ежедневно после 10:00 по времени компьютера; версию можно пропустить.

## Углы окон и таймлайн в 0.36.4

Редактор видео и панель записи используют единый контур скругления на
прозрачном фоне. Ручки границ фрагмента увеличены; синяя рамка таймлайна
заканчивается между ручками. При перетаскивании границы курсор воспроизведения
скрыт, а предпросмотр по-прежнему показывает текущий кадр границы.
Итоговый размер ручек — 16 × 56 px. Проверки и сборка:
[docs/qa-0.36.4-video.md](docs/qa-0.36.4-video.md).

## Аннотирование в 0.36.3

В редакторе закреплённого снимка «Сохранить» или Enter открывают диалог
сохранения изображения с текущими аннотациями. Удержание кнопки показывает
быстрые папки из настроек. Экспорт сохраняет исходное разрешение и оставляет
редактор открытым; «Готово» применяет изменения к закрепу.

Копирование готового изображения назначено на C без Ctrl в захвате и
редакторе аннотаций. Клавиша работает и в русской раскладке; при вводе текста
C и Enter сохраняют обычное поведение текстового поля.
Проверки и сборка: [docs/qa-0.36.3-annotation.md](docs/qa-0.36.3-annotation.md).

## Запись и редактор видео в 0.36.0 (Windows)

В трее выберите «Записать видео области» или нажмите значок камеры справа от
поиска в палитре. Выделите область на одном мониторе, выберите 15/30 кадров/с
и при необходимости включите «Звук системы». Enter начинает запись;
плавающая панель позволяет приостановить и завершить её.

После завершения открывается отдельное окно «Обрезка видео»: предпросмотр,
миниатюры, границы фрагмента, обрезка кадра и сохранение MP4/GIF.
Для небольшого MP4 по умолчанию выбрано «Компактно»; показан приблизительный
размер. У GIF настраиваются ширина и частота, звук отсутствует.

Встроен [wcap](https://github.com/mmozeiko/wcap): Windows Graphics Capture,
Media Foundation H.264/AAC и WIC GIF. FFmpeg и дополнительные runtime-библиотеки
для видео не поставляются. Требуется Windows 10 1903+ или Windows 11 с
доступными компонентами мультимедиа. Аппаратный кодировщик используется при
поддержке GPU; предусмотрен программный кодировщик Windows.

Для сборки дополнительно нужен Windows SDK с `fxc.exe` и MSVC с поддержкой
C11 atomics. Подробности и результаты проверки: [docs/qa-0.36.0-video.md](docs/qa-0.36.0-video.md).

## Исправления видео в 0.36.1

Добавлены заметная кнопка «Плей/Пауза» и непрерывная перемотка зажатой ЛКМ.
При движении начала или конца фрагмента предпросмотр показывает кадр этой
границы. Обрезка кадра подтверждается кнопкой «Применить обрезку»; после этого
предпросмотр показывает результат и его размеры. Есть отмена и сброс обрезки.

Исправлены цветные полосы при экспорте областей с шириной, не кратной 16:
чтение декодированных кадров учитывает фактический шаг строки. Проверка MP4
и GIF сравнивает весь кадр с исходной записью, включая текст интерфейса и
маленькую обрезку 80 × 72. Результаты: [docs/qa-0.36.1-video.md](docs/qa-0.36.1-video.md).

## Интерфейс видео в 0.36.2

Кнопка «Видео» находится перед «Сохранить» на панели выделения; V начинает
запись выбранной области. Панель записи занимает одну строку снизу по центру
рабочей области монитора. F11 приостанавливает/продолжает запись, F12 завершает;
клавиши работают при фокусе вне панели.

Списки настроек видео используют меню в стиле Snipcast. Удержание «Сохранить»
показывает быстрые папки из настроек скриншотов; отпускание над папкой сохраняет
видео в выбранном формате. Успешное сохранение закрывает редактор, а отмена
диалога и ошибки оставляют его открытым. Исправлены курсоры обрезки и нативные
углы; окно редактора доступно для скриншотов. Проверка: [docs/qa-0.36.2-video.md](docs/qa-0.36.2-video.md).

## Курсор таймлайна в 0.36.5

Перетягивание границ меняет кадр предпросмотра, но сохраняет положение курсора
воспроизведения. После отпускания ручки курсор появляется в прежней позиции.
Воспроизведение продолжается оттуда; если позиция вне выбранного фрагмента,
оно начинается с новой границы начала. Проверка: [docs/qa-0.36.5-video.md](docs/qa-0.36.5-video.md).
