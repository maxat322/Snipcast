# Внешний HTTP API Snipcast

Локальный HTTP-сервер для скриптов и автоматизации: снятие скриншотов (всего экрана
или области), распознавание текста, запуск пресетов. Сервер слушает **только
`127.0.0.1`** — доступ возможен исключительно с этого же компьютера.

## Включение

Настройки → «Скриншот» → блок **«Внешний API (для скриптов)»**:

- переключатель «Включить внешний API»;
- порт (по умолчанию `52300`, допустимо 1024–65535). Смена порта или токена
  применяется сразу — перезапуск приложения не нужен.

Если порт уже занят другой программой, сервер не запустится (ошибка пишется в лог);
освободите порт или укажите другой.

## Аутентификация

Все запросы, кроме `GET /health`, требуют токен — 32 hex-символа. Он передаётся
одним из двух заголовков:

```
X-Snipcast-Token: <токен>
Authorization: Bearer <токен>
```

Токен автоматически создаётся при первом включении API и хранится в файле
`api-token` в папке данных Snipcast:

- по умолчанию: `C:\Snipcast\api-token`;
- путь можно переопределить переменной окружения `SNIPCAST_DATA_DIR`.

В настройках токен можно **показать**, **скопировать** и **перевыпустить** —
после перевыпуска старый токен перестаёт работать сразу.

## Эндпоинты

### `GET /health`

Проверка живости, токен не нужен.

```json
{ "ok": true, "version": "0.34.2" }
```

### `POST /capture`

Сделать скриншот. Тело — JSON, все поля необязательны:

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `name` | string | шаблон из настроек (`Snip {datetime}`) | Шаблон имени файла; поддерживает подстановки `{date}`, `{time}`, `{datetime}`, `{n}` |
| `dir` | string | общая папка из настроек | Папка сохранения |
| `region` | [x, y, w, h] | весь виртуальный экран | Область снимка в **физических пикселях** виртуального экрана (координатное пространство всех мониторов). Обрезается по экрану; если не пересекается с ним — ошибка 500 «область вне экрана» |
| `format` | `"png"` \| `"jpeg"` | из настроек (`png`) | Формат сохраняемого файла |
| `quality` | 1–100 | из настроек (90) | Качество, только для `jpeg` |
| `ocr` | boolean | `false` | Распознать текст на снимке и вернуть в поле `text` |
| `ocr_engine` | `"system"` \| `"paddle"` | из настроек | Движок OCR; `paddle` доступен только в Windows |
| `ocr_language` | string | из настроек | `"auto"` или код языка BCP-47, например `"ru-RU"` |
| `copy` | `"image"` \| `"path"` \| `"none"` | `none` | Что положить в буфер обмена: сам снимок или путь к файлу |
| `pin` | boolean | `false` | Дополнительно закрепить снимок поверх всех окон |

Ответ `200`:

```json
{
  "ok": true,
  "path": "C:\\Snipcast\\Snips\\Snip 2026-10-05 120000.png",
  "text": null,
  "width": 2560,
  "height": 1440,
  "ms": 312
}
```

- `path` — абсолютный путь к сохранённому файлу. Само изображение в ответе
  не передаётся;
- `text` — распознанный текст (или `null`, если `ocr` не включён);
- `width`, `height` — фактический размер снимка в пикселях;
- `ms` — время выполнения запроса в миллисекундах.

### `POST /preset`

Запустить пресет скриншота по его id (id виден в настройках пресетов):

```json
{ "id": "мой-пресет" }
```

- пресет **с выделением области**: ответ `{"ok": true}` приходит сразу, окно
  выделения откроется на экране;
- **беззвучный** пресет выполняется синхронно: `{"ok": true}` при успехе или
  `{"ok": false, "error": "..."}` при ошибке.

## Ошибки

Все ошибки — JSON с полем `ok: false`:

| Код | Причина | Пример ответа |
|---|---|---|
| 400 | невалидный JSON в теле | `{"ok": false, "error": "неверный JSON: ..."}` |
| 401 | нет или неверный токен | `{"ok": false, "error": "неверный или отсутствующий токен (заголовок X-Snipcast-Token)"}` |
| 404 | неизвестный путь или метод | `{"ok": false, "error": "нет такого пути (POST /capture, POST /preset, GET /health)"}` |
| 500 | ошибка захвата / сохранения / OCR | `{"ok": false, "error": "область вне экрана"}` |

Типичные тексты ошибок 500: «область вне экрана», «не указана папка сохранения:
задайте dir в запросе или папку по умолчанию в настройках», «PaddleOCR доступен
только в Windows».

## Ограничения

- запросы обрабатываются **строго последовательно**, по одному;
- CORS-заголовков нет — из веб-страниц в браузере API недоступен (для локальных
  скриптов это не мешает);
- скриншот не возвращается в теле ответа — только файл на диске и его `path`.

## Примеры

### curl

```bash
TOKEN=$(cat /c/Snipcast/api-token)

# Проверка живости (без токена)
curl http://127.0.0.1:52300/health

# Скриншот всего экрана в свою папку
curl -X POST http://127.0.0.1:52300/capture \
  -H "X-Snipcast-Token: $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"dir":"C:/Temp","name":"shot {datetime}","format":"png"}'

# Область экрана + распознавание текста + путь в буфер обмена
curl -X POST http://127.0.0.1:52300/capture \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"region":[100,100,800,600],"ocr":true,"ocr_language":"ru-RU","copy":"path"}'

# Запуск пресета
curl -X POST http://127.0.0.1:52300/preset \
  -H "X-Snipcast-Token: $TOKEN" \
  -d '{"id":"мой-пресет"}'
```

### Python

```python
import json, pathlib, urllib.request

token = pathlib.Path(r"C:\Snipcast\api-token").read_text(encoding="utf8").strip()

req = urllib.request.Request(
    "http://127.0.0.1:52300/capture",
    data=json.dumps({"region": [100, 100, 800, 600], "ocr": True}).encode(),
    headers={"X-Snipcast-Token": token, "Content-Type": "application/json"},
    method="POST",
)
with urllib.request.urlopen(req, timeout=30) as resp:
    result = json.load(resp)
print(result["path"])
print(result["text"])
```
