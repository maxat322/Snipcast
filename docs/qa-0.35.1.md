# Проверка Snipcast 0.35.1

Дата: 2026-10-07. Нативные экземпляры использовали отдельные `SNIPCAST_DATA_DIR`, идентификатор `com.snipcast.selection-qa` и порты WebView2/CDP. Настройки и работающий пользовательский экземпляр не заменялись тестовыми.

## Функциональные проверки

- `tests/capture_0351.py`: обе темы и DPR 1/1.5/2; уход подсказок, прозрачность для мыши, расположение бейджей под названиями; A с отрицательными координатами и разными масштабами мониторов; физическая KeyA с русским значением; Numpad1–8, включая коды при выключенном NumLock; OCR/сумма/существующая проверка ключа ИИ; Пробел и точная геометрия закрепа; ввод текста не запускает действия; проценты, обводка в PNG, изменение рамки и A сохраняют текст; геометрия сглаженного пути и попадание мыши.
- Форма обводки в native textarea сверена с Canvas PNG. Chromium округляет базовую линию текстового поля: допускается вертикальное расхождение 1 физического пикселя при совпадении контура более 95%.
- `tests/capture_035.py`: 6 групп регрессий — захват между виртуальными мониторами, разные DPR/масштабы, точные пиксели, Shift, продолжение свободного штриха, перемещение/удаление, история, ввод текста, сохранение/отмена и точные суммы.
- `tests/capture_text.py`: 18 регрессий текста, переносов, каретки, изменения рамки, экспорта, нативной истории ввода и сгруппированной истории параметров.
- `tests/capture_assist.py`: лупа, исходные цвета, кандидаты, поздние ответы, обе темы/DPR и автосохранение пресета — как кликом, так и клавишей A — ровно один раз.
- `tests/capture_opening.py`: 7 проверок открытия, готовности кадра, прозрачности, повторного открытия, устаревших событий и reduced motion.
- `tests/pin_annotation.py`: 8 групп — обе темы/DPR, копирование/готово/отмена, сохранение PNG и ошибка записи, оставляющая редактор открытым.
- `cargo test --lib`: 16 тестов прошли. `cargo check` и сборка TypeScript/Vite прошли.

## Нативный Windows/WebView2

- `tests/pin_reopen_native.py`: до изменения — 20 циклов исходного exe 0.35.0. Присланная шапка в этом прогоне не воспроизвелась; обнаружены флаги native caption (`0x14c80000`).
- После изменения — 20 циклов итогового QA release exe, чередование «Готово»/«Отмена», все 5 инструментов, обе темы, включение обводки. Ещё 3 цикла на втором закрепе с масштабом 50%. Положение изображения, масштаб и восстановление геометрии сохранены; client offset 0; caption отсутствует (`0x14000000`). Запросы старого сеанса игнорируются и во время нового редактирования, и после завершения.
- `tests/pin_annotation_native.py`: контекстное меню, настоящая Windows image clipboard с точными пикселями, аннотации и исходное разрешение PNG, готово/отмена/повторное открытие, выбранный закреп, прозрачность WebView и объединённый native region, исключающий пустую область.
- `tests/capture_035_native.py --skip-update --new-hotkeys`: один overlay на доступном рабочем столе, физический курсор на один пиксель, Ctrl+C с точными размерами/пикселями буфера, A выбирает весь текущий монитор, Пробел создаёт выбранный закреп 640×400 и закрывает захват. Настоящий Windows OCR даёт сумму `10,3`; текстовый буфер проверен. Нативное сохранение PNG проверено по пикселям.

## Производительность

Измеряется интервал между кадрами через requestAnimationFrame, а не аппаратная задержка мыши до свечения экрана. CPU 6× — эмуляция ограничения процессора. JS heap не включает canvas, GPU и память native/WebView процессов.

Браузер: 120 движений выделения с лупой. Итоговые измерения выполнялись отдельно от сборки и других тестов. При первичной реализации принудительное чтение размеров подсказок на каждом движении ухудшило результат; после кеширования геометрии и memo это устранено.

## Границы проверки

Доступен один физический монитор 1920×1080, DPI 100%. Два монитора, отрицательные координаты и DPI 150/200% проверены в браузерной эмуляции, не на реальной паре экранов. Реальный слабый ПК недоступен. Русские физические коды и NumLock-off проверялись синтетическими событиями; системную раскладку и NumLock пользователя не переключали. Внешний запрос к ИИ не выполнялся: покрыта существующая проверка отсутствующего ключа. Отмена «Сохранить как» проверена через browser bridge; native PNG сохранён командой. Установщик и GitHub Release не запускались.

Итоговый `dist-release/snipcast.exe` — стандартный идентификатор приложения и версия 0.35.1. Нативные тесты выполнены на release exe с тем же frontend/backend и отдельным QA-идентификатором.
