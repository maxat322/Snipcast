# Проверка Snipcast 0.35.2

Уточнение от 2026-10-08: выводы ниже о полном удалении системной полосы и сглаживании траектории оказались недостаточно проверены. На 0.35.2 воспроизведена видимая шапка при снятом `WS_CAPTION`; количество оттенков края не подтверждает округление формы. Исправления и полное сравнение рабочего стола приведены в [qa-0.35.3.md](qa-0.35.3.md). Ниже сохранён исходный отчёт.

Дата: 2026-10-07. Нативные проверки выполнялись в Windows/WebView2 с отдельными профилями `SNIPCAST_DATA_DIR`, идентификатором `com.snipcast.selection-qa` и портами CDP. Пользовательский процесс и его закрепы не закрывались. Незакоммиченные изменения сохранены.

## Нативный редактор и закрепы

- В exe 0.35.1 воспроизведён возврат `WS_CAPTION` после hide/show: стиль меняется с `0x14000000` на `0x14c80000`. Обычные циклы редактора сами по себе этот путь не проверяли. В 0.35.2 добавлен оконный обработчик, блокирующий стили системной рамки до их применения через [WM_STYLECHANGING](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-stylechanging).
- Итоговый QA release: 20 циклов с чередованием «Готово»/«Отмена», пятью инструментами, обеими темами и обводкой; ещё 3 цикла на втором закрепе в масштабе 50%. Дополнительно проверены hide/show, фокус и колесо масштаба обычного закрепа. Флаги caption не вернулись, client offset остался 0, исходная геометрия и положение изображения сохранены. Старые запросы сеансов игнорируются.
- Проверены реальные пиксели рабочего стола в прозрачной верхней полосе окна после повторного показа: системная шапка не перекрывает фон. Это отдельная проверка от скриншота WebView, который не показывает non-client оформление Windows.
- В `pin_annotation_native.py` проверены четыре иконки меню, точные пиксели/размеры настоящего Windows image clipboard, аннотирование, готово/отмена, масштаб и положение, колесо текста и Esc после обводки. Native region содержит место на 35 CSS px ниже тулбара для тени и исключает пустое окружение окна.
- Реальное меню трея открыто через уведомление его собственного окна в изолированном процессе; подписи и координаты прочитаны из системного popup menu. Клик «Закрыть все закрепы» закрыл оба тестовых окна. Пользовательский процесс не участвовал.
- Новый сглаженный штрих проверен настоящими движениями указателя в WebView2: 96 значений покрытия alpha. Сохранённый PNG и предпросмотр совпадают с максимальным различием 3 единицы цвета; браузерный прогон дал 204 значения alpha и различие 1. Исправлена именно запись дублирующихся точек реальных жестов; дополнительно применяется сглаживание краёв в увеличенном буфере границ штриха.
- `capture_035_native.py --skip-update --new-hotkeys`: физический курсор, Ctrl+C и точный image clipboard, A, Пробел, OCR с суммой `10,3`, PNG-сохранение. Использован итоговый QA release.

## Производительность

Замеры выполнялись отдельно от сборки и других тестов. Интервал между RAF-кадрами не равен аппаратной задержке мыши до изображения. CPU 6× — эмуляция, а не реальный слабый компьютер.

Последовательный повторный прогон нативных release exe, один физический монитор:

| Измерение | 0.35.1 | 0.35.2 |
| --- | --- | --- |
| Первое открытие, мс | 506.6 | 541.3 |
| Повторные открытия, мс | 320.1 / 317.3 / 302.4 | 332.2 / 322.2 / 304.6 |
| Штрих, CPU 1×, медиана / p95, мс | 16.7 / 16.9 | 16.7 / 16.9 |
| Штрих, CPU 6×, медиана / p95, мс | 16.6 / 17.7 | 16.6 / 19.4 |

В первом прогоне 0.35.2 отмечено одно открытие за 1444.7 мс. Повторный последовательный прогон обеих версий не повторил выброс; исходные результаты сохранены в `docs/qa-artifacts/native-perf-0352-after/results.json`. Причина одиночной задержки не установлена; ускорение открытия не заявляется.

Браузер, 120 движений выделения с лупой:

| Виртуальные экраны | CPU | Медиана / p95, мс |
| --- | --- | --- |
| 1 | 1× | 16.7 / 17.0 |
| 1 | 6× | 21.8 / 31.3 |
| 2 | 1× | 16.7 / 16.9 |
| 2 | 6× | 21.9 / 28.1 |

JS heap около 10.2–10.8 МБ; это не общий расход памяти native/WebView/GPU. Буфер сглаживания общий и ограничивает дополнительное разрешение больших штрихов, не увеличивая весь canvas рабочего стола в четыре раза.

## Границы проверки

Нативно доступен один монитор с DPI 100%. Два монитора, отрицательные координаты и DPI 150/200% проверены браузерными fixtures; физическая пара экранов не проверена. Физические коды русской раскладки и нумпада проверены без изменения системной раскладки/NumLock. Ежедневные обновления в этом исправлении не менялись и повторно не проверялись. Сетевой запрос ИИ не выполнялся без настроенного ключа. Отмена Save As проверена контролируемым диалогом; нативно проверено само PNG-сохранение.
