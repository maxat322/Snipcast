# Snipcast 0.36.11 — перетаскивание групп шаблонов

Группы во вкладке «Шаблоны» можно перетаскивать мышью. На границе соседней группы появляется маркер вставки, перемещаемая группа становится полупрозрачной. Длинный список прокручивается при удержании указателя возле края. Esc, потеря фокуса и отпускание вне списка отменяют перенос. Обычный клик продолжает выбирать группу.

Обычные и мастер-группы перемещаются одинаково. Выбор группы, содержимое шаблонов, цвета и путь к мастер-файлу сохраняются. Порядок записывается существующей командой `snipcast_save_template_store`: backend сохраняет группы в манифест в порядке массива; новые форматы данных и зависимости не добавлены.

Сохранения шаблонов и порядка поставлены в очередь. Ответ более раннего сохранения не заменяет более позднюю правку. Перенос учитывает уже отправленное автосохранение. При ошибке переноса без последующей правки прежний порядок восстанавливается; ошибка показывается в настройках.

## Проверки

По файлам текущей задачи выбран `--focus template-groups`; запущен только `tests/template_groups_ui.py`. Захват и запись видео не запускались.

Браузерный React-интерфейс с имитацией Tauri IPC проверен настоящими событиями указателя Playwright в обеих темах:

- перенос до/после соседней группы в обе стороны;
- сохранение выделения, всех данных и мастер-группы;
- отмена по Esc и за пределами списка, отсутствие записи при неизменном порядке;
- восстановление порядка после повторного открытия с сохранёнными данными стенда;
- перенос при задержанном автосохранении текста, сохранность правки и отсутствие параллельных записей;
- ошибка сохранения, возврат к прежнему порядку и успешный повтор;
- автопрокрутка списка из 18 групп.

Нативный backend этой задачи не изменён; отдельный прогон с пользовательскими группами не выполнялся.
