# Snipcast 0.36.2 — интерфейс видео

Проверка от 12 октября 2026 года. Изменения сделаны в существующем рабочем
каталоге с сохранением прочих незакоммиченных изменений. Публикация не выполнялась.

## Изменения

- Нативные `<select>` заменены меню Snipcast для качества видео, ширины/частоты
  GIF и частоты записи области. Поддерживаются мышь, стрелки, Home/End,
  Enter/Пробел и Escape; меню открываются вверх у нижнего края окна.
- Успешное обычное или быстрое сохранение закрывает редактор. Отмена диалога,
  отсутствующая папка и ошибки экспорта оставляют запись и редактор открытыми.
- Из редактора удалена нижняя кнопка «Отмена». Крестик в заголовке остаётся.
  Отмена обрезки и отмена выполняющегося экспорта сохраняют свои отдельные действия.
- Удержание «Сохранить» 250 мс показывает папки `screenshotQuickLocations`.
  Отпускание над папкой сохраняет MP4/GIF с текущей обрезкой и параметрами.
  Отпускание вне меню отменяет выбор. Имена и защита от совпадений используют
  существующий механизм путей скриншотов.
- Курсоры восьми маркеров обрезки соответствуют стороне или диагонали изменения.
- Окно редактора доступно для скриншотов: исключение из захвата осталось у панели
  записи. В Windows 11 используются нативные скругления DWM без лишней рамки;
  скругление HTML не заменяет форму нативного окна. Предусмотрен fallback через
  оконную область для Windows без поддержки атрибута DWM.
- Панель записи 300 × 44 логических пикселя, одна строка без информации о размере
  кадра. Положение — по центру нижнего края рабочей области выбранного монитора,
  с отступом 16 логических пикселей над панелью задач; масштаб монитора учитывается.
- F11 приостанавливает/продолжает, F12 завершает запись при фокусе вне панели.
  Обработка существует только во время записи; поток и hook удаляются при завершении.
  Повторные keydown при удержании не переключают паузу многократно.
- «Видео» перенесено непосредственно перед «Сохранить» на панели выделения,
  добавлены V в подсказке и обработка физической клавиши KeyV, включая русскую раскладку.

F12 нельзя назначать обычным RegisterHotKey: это ограничение Windows.
Используется системный keyboard hook в отдельном небольшом потоке с резервом
стека 128 КиБ; рассматриваются только две клавиши управления. Есть резервная
проверка состояния этих клавиш в существующем цикле записи на случай удаления
hook системой. События hook и проверки объединяются, чтобы исключить двойное
переключение. Состояние клавиш сбрасывается между записями; key-up передаётся
Windows, чтобы F11/F12 не оставались зажатыми после остановки. Новые runtime-библиотеки не добавлялись.
Основание: [RegisterHotKey](https://learn.microsoft.com/ru-ru/windows/win32/api/winuser/nf-winuser-registerhotkey),
[LowLevelKeyboardProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc).

## Проверка

`npm run build`, `cargo check`, `cargo test --lib` (19 тестов) прошли.
Нативная проверка `tests/video_native.py` использует отдельный identifier
`com.snipcast.video-qa`, изолированные настройки/файлы и реальный WebView2/WGC.

Проверяются:

- размеры панели и её физическое положение относительно рабочей области;
- F11/F12 через Windows SendInput при фокусе в другом окне, остановка времени на паузе;
- отсутствие системных списков и обычной кнопки «Отмена», выбор мышью и клавиатурой;
- нативный атрибут скругления DWM и изменение размеров редактора;
- снимок редактора через настоящий скриншотер Snipcast, с проверкой цвета кнопки;
- все курсоры обрезки, перемотка и кадры границ, применение/отмена обрезки;
- успешное сохранение MP4 через настоящий диалог Windows и автоматическое закрытие;
- удержание/отмена выбора быстрой папки, ошибка папки без закрытия и быстрый GIF с закрытием;
- V из обычной панели скриншотов и расположение «Видео» перед «Сохранить»;
- MP4/GIF с полным сравнением кадров, звук AAC, отмена экспорта без перезаписи,
  следующий захват и очистка исходных временных записей.

Проверена Windows 11, масштаб 100%, программный кодировщик H.264. Windows 10,
fallback скругления, другие GPU и масштаб 150/200% в этом прогоне не проверялись.

Финальная release-проверка прошла без ошибок страницы, лог приложения пуст.
Дополнительно тот же EXE проверен с повторными keydown F11 и проверкой, что
F11/F12 отпущены после остановки. Повторная запись и быстрый GIF завершились успешно.
