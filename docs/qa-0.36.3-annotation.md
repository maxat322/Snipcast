# Snipcast 0.36.3 — сохранение аннотаций и клавиша C

## Изменения

- В редакторе закреплённого снимка добавлена кнопка «Сохранить». Enter открывает тот же диалог сохранения. Удержание кнопки открывает быстрые папки из настроек скриншотов.
- Файл содержит текущие аннотации и сохраняет исходное разрешение. После экспорта редактор остаётся открытым; закреп обновляется кнопкой «Готово».
- Готовое изображение копируется клавишей C без Ctrl, в том числе при русской раскладке. Подсказки обновлены в панели захвата и аннотирования. В текстовом поле C, Enter и обычные сочетания редактирования не перехватываются.
- Уведомление в редакторе закрепа привязано к изображению: оно больше не растягивает прозрачное окно вниз. Меню быстрых папок включено в нативную область окна, принимающую клики.
