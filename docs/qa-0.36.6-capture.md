# Snipcast 0.36.6 — захват, история и настройки

Проверка 13 октября 2026 года. Подготовлена локальная версия; публикация GitHub не выполнялась.

## Реализовано

- Alt показывает центральный пунктирный крест через экран. Копирование, сохранение и закрепление фиксируют Alt до асинхронного действия и впечатывают крест внутри выбранной области. Потеря фокуса скрывает направляющие.
- В «Основных» переназначаются Enter / Пробел / C. Подписи обновляются; ввод текста имеет приоритет, физические клавиши работают с русской раскладкой. Проверяются дубликаты, инструменты, история и отмена, включая Shift и дополнительный Alt.
- История содержит максимум 30 полноэкранных PNG с метаданными области в `screenshots-history` пользовательской папки данных. «−»/«+» и NumPad открывают старые снимки без аннотаций, возвращают текущую правку вместе с отменой; повреждённые и запоздавшие загрузки обрабатываются. Изображения загружаются по одному, изменённое соотношение экранов вписывается с сохранением пропорций.
- Стандартный пресет «Весь экран на рабочий стол» добавляется один раз: системный Desktop, Alt+PrintScreen, `Snip {datetime}`, выбранный формат. Удалённый пресет не возвращается. Конфликт в настройках оставляет пресет без комбинации с пояснением. Полноэкранное действие во время выделения использует чистый исходный экран без панелей и направляющих.
- Добавлены чёрный и фиолетовый, второй насыщенный ряд палитры, центрирование вспомогательной панели под инструментом с ограничением краёв и переносом наверх. Заголовки панели и мешающий `title` закрепа убраны. Shift выравнивает редактируемые концы; квадрат и круг сохраняют равные стороны.
- Быстрые папки открываются через 250 мс наведения в захвате, аннотациях и видеоредакторе. Переход в меню сохраняет его, выход закрывает через 150 мс; наведение не сохраняет файл. Обычный клик и удержание сохранены.

## Буфер Windows

Четыре небольших последовательных изображения остались в Win+V. Сохранение и закрепление не изменяют номер последовательности буфера. Публикуются PNG и DIBV5, запрета на системную историю и явной очистки истории не найдено.

Для случайного изображения 1536 × 1024 PNG занимает **4 726 345 байт**, DIB — **6 291 456 байт**. Обычный буфер сохраняет полное изображение с точными пикселями, Win+V нового элемента не создаёт. Это соответствует [ограничению Microsoft в 4 МБ на элемент](https://support.microsoft.com/en-US/Windows/Apps/using-the-clipboard). Полный снимок остаётся в истории Snipcast. Системная история специально не очищалась.

## Цвет

Исправлено дробное повторное масштабирование исходного фрагмента при экспорте: чистые пиксели PNG совпадают с источником, включая масштаб 150% и однопиксельные детали.

На активном профиле **AOC Generic PnP-1.icm** воспроизведено второе преобразование RGB в отображении WebView2. Данные PNG и canvas совпадали, но показ закрепа отличался: средняя абсолютная ошибка на градиенте **4,047** уровня. WebView2 теперь запускается с `--force-color-profile=srgb`, сохраняя дополнительные диагностические аргументы. Яркость и насыщенность пикселей не меняются. После исправления PNG, canvas и показ закрепа совпадают точно на градиенте и фотографии.

JPEG при качестве 90: средняя абсолютная ошибка **0,477** на градиенте и **1,093** на фотографии; это ожидаемое сжатие. HDR поддерживается монитором, но выключен; активен 8-битный SDR. HDR и другие аппаратные ICC-профили остаются непроверенными.

## Выбор тестов

`npm run test:changed -- --list --files <изменённые файлы>` показывает подходящие проверки; без `--list` выполняет их. Без списка файлов база — последний тег выпуска, можно указать `--base`. Сравнивается фактическое содержимое, включая файлы, которые остались неотслеживаемыми в текущем checkout.

Для `src/video/VideoApp.tsx` и `src/video/video.css` выбирается только короткий `tests/video_editor_ui.py`. Полная нативная запись не выбирается для интерфейсных изменений. `--native` включает соответствующие нативные проверки для изменённого backend, `--full-video` явно запрашивает полный прогон. Нативным сценариям требуется изолированный QA EXE в `SNIPCAST_QA_EXE`; браузерным — локальный Vite на 1420.
