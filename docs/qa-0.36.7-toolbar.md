# Snipcast 0.36.7 — подсказки и насыщенная палитра

В панели подсказок выделения добавлены Alt для центральных направляющих,
Alt вместе с действием для сохранения направляющих в снимке, «−»/«+» для
истории с указанием NumPad. Alt и история видны сразу после открытия окна;
подсказка сохранения направляющих появляется после выбора области.

У фигур, текста и обводки оставлены десять насыщенных цветов в одном ряду.
Приглушённый ряд удалён; белая и чёрная кнопки сохраняют контрастные рамки.
Ранее созданные аннотации сохраняют свои цвета.

Проверки ограничены этим интерфейсом:

`npm run test:changed -- --focus capture-toolbar --files src/capture/CaptureOverlay.tsx src/capture/CaptureShortcuts.tsx`

Браузерный сценарий проверяет обе темы при 100/150/200%, подсказки до и после
выделения, Alt, ровно десять цветов для фигуры/текста/обводки, выбор фиолетового,
рамки нейтральных цветов и размещение подсказок внутри экрана.

Нативная проверка использует `tests/capture_0366_native.py --toolbar-only`,
отдельный идентификатор `com.snipcast.toolbar-qa-0367`, изолированные данные
и WebView2/CDP. Она проверяет только подсказки и палитру. Запись видео,
экспорт, буфер Windows и история файлов в этом обновлении не проверяются повторно.

## Приоритет сочетаний

Текущий обработчик клавиш работает в WebView2; отмена DOM-события не подавляет
глобальные сочетания других программ. У обычного RegisterHotKey нет параметра
приоритета. Временный WH_KEYBOARD_LL позволяет обработать сочетание раньше
обычной доставки и не передать его дальше: [Microsoft](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc).

Для такой отдельной доработки перехват должен работать только при активном
выделении, пропускать ввод текста и отключаться при потере фокуса, закрытии
окна и открытии диалога. Это потребует отдельной проверки конфликта с другим
приложением. В 0.36.7 перехват не добавлен; вопрос пользователя исследован.
