# Snipcast 0.36.9 — настройки горячих клавиш

## Что изменилось

- Пять строк остаются в одном списке. Подписи используют обычное начертание, заголовки сохраняют выделение.
- Подписи: «Палитра шаблонов», «Скриншот», «Скриншот: сохранить в файл», «Скриншот: закрепить», «Скриншот: копировать в буфер».
- Вместо текстовых кнопок очистки — иконка ластика с доступным названием и подсказкой. Очистка обновляет конфигурацию, а не только отображаемое поле.
- «Вернуть по-умолчанию» сохраняет пять сочетаний одним запросом. Остальные настройки, быстрые папки и пресеты не сбрасываются.
- Значения соответствуют новым установкам: Ctrl+Shift+\, PrintScreen, Enter, Space, C. На macOS CommandOrControl отображается как Cmd.
- В узком окне подписи переносятся над полями; иконки и поля сохраняют выравнивание.

## Проверки этой задачи

В список `--files` включены только изменённые этой задачей файлы. Выбран `--focus settings-hotkeys`: одна проверка `tests/settings_hotkeys_ui.py`, без захвата экрана, видео, экспорта и отложенного нативного теста перехвата клавиатуры.

Браузерный тест настоящего React-интерфейса с имитацией Tauri IPC прошёл для светлой/тёмной темы и ширины 950/720 px:

- точные подписи, обычное начертание и пять иконок;
- очистка каждого сочетания без изменения остальных полей конфигурации;
- восстановление всех пяти значений одним сохранением, сохранность пользовательских пресетов;
- блокировка полей на время восстановления;
- запись нового сочетания после восстановления;
- сообщение при отклонении сохранения, сохранность прежнего значения, успешный повтор;
- отсутствие наложения подписей, полей и кнопок, горизонтального переполнения и ошибок страницы.

Значения сброса дополнительно сверены с исходными значениями `src-tauri/src/data.rs`. Старая проверка общего списка 0.36.8 обновлена под новые подписи; весь прежний сценарий захвата не запускался.
