# Snipcast 0.36.12 — проверка выпуска

16 октября 2026. Портативный EXE собран через Tauri CLI, без `inline-qa`.
Версии package.json, обоих записей package-lock.json, Cargo.toml, Cargo.lock
и tauri.conf.json согласованы; FileVersion EXE — 0.36.12. В EXE найдена ссылка
на фактически собранный frontend `index-2iPiSldW.js`.

Из 102 производственных файлов предыдущего выпуска поведение изменено только
в `src-tauri/src/suggestions_windows.rs`. Его SHA-256 совпадает с исходником
сборки, для которой пользователь подтвердил: «Шаблон вставился, команда удалена».
Остальные изменения производственного дерева — номер выпуска.

Выбор проверен через `test:changed --list --focus text-suggestions --files`
с явным перечнем файла вставки и пяти файлов версий; затем выполнена та же
команда без `--list`. Прошли 16 тестов, включая 60 настоящих удалений/вставок
в EDIT на отдельной window station со своим рабочим столом и буфером обмена.
Фокус и буфер пользователя для автоматических тестов не использовались.

Ограничения и воспроизведение исходной регрессии:
[qa-insertion-regression.md](qa-insertion-regression.md). Проверка выпуска
не означает совместимость всех редакторов и терминалов.

EXE и checksum подготовлены для публикации в обычном GitHub Release 0.36.12
как последнем выпуске для автообновления. Для загрузки используются уже
проверенные локальные файлы; перед публикацией проверяется обратное скачивание.
Снимок исходников создаётся от 0.36.11 в `codex/release-0.36.12` и теге
`0.36.12`, с сохранением рабочей ветки main и её индекса. `[skip ci]` исключает
повторную сборку и замену проверенного EXE через Actions.

Обе локальные копии EXE обновлены. Предыдущий экземпляр завершён штатно после
проверки отсутствия открытых окон записи/редактирования. После `cargo clean`
изолированного target запущен `dist-release/snipcast.exe`; проверены процесс,
SHA-256 и готовность окон/трея. Пользовательские настройки и шаблоны сохранены.

Компактные подтверждения: [qa-artifacts/release-03612](qa-artifacts/release-03612/).
