# Snipcast 0.36.13 — проверка выпуска

20 октября 2026. Выпуск включает направляющие курсора при Alt, очистку аннотаций с отменой, редактируемые объекты в истории снимков, совместное размещение двух панелей и удаление кнопки видео из обычной палитры.

Сравнение с тегом 0.36.12 выявило четыре изменённых производственных файла и новый `src/capture/annotationCoordinates.ts`. Остальные производственные исходники сохранены. Версия синхронизирована в package.json, двух записях package-lock.json, Cargo.toml, Cargo.lock и tauri.conf.json.

Проверки выбраны через `npm run test:changed -- --list --files` с явным списком файлов захвата, палитры и версии; затем запущен тот же набор без `--list`. Нативная проверка отдельно ограничена историей снимков. Запись и экспорт видео не запускались.

Браузерные проверки охватывают светлую и тёмную темы, DPI 1 / 1.5 / 2, движение и скрытие направляющих, отсутствие новых линий в экспорте, очистку активного текста, undo/redo, все восемь типов аннотаций, изменение размера окна и размещение панелей. Нативная проверка использует собственный идентификатор и каталог данных, чтобы не менять пользовательские настройки и историю.

Портативный EXE собирается через `npm run tauri build -- --no-bundle`, без функции `inline-qa`. В нём проверяются версия, обычный идентификатор приложения и наличие фактического frontend. Публикуются этот EXE и SHA-256; загруженные вложения скачиваются обратно и сверяются.

Снимок релиза создаётся от 0.36.12 в `codex/release-0.36.13` и теге `0.36.13`. Рабочие HEAD, индекс и остальные локальные изменения сохраняются. Коммит содержит `[skip ci]`, чтобы Actions не заменил проверенный EXE повторной сборкой.

Результаты: [qa-artifacts/release-03613](qa-artifacts/release-03613/).
