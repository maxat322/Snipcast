# Snipcast 0.36.14 — проверка выпуска

22 октября 2026. Выпуск основан на 0.36.13 и включает изменения четырёх производственных файлов: `src/capture/CaptureOverlay.tsx`, `src/capture/TextEditor.tsx`, `src/capture.css`, `src-tauri/src/capture_keyboard.rs`. Версия синхронизирована в package.json, package-lock.json, Cargo.toml, Cargo.lock и tauri.conf.json.

Непосредственно перед выпуском прошли три браузерных набора: базовый захват, аннотации области и редактор закрепа. Подтверждены совместное скрытие панелей, сохранение их геометрии, отсутствие перехвата указателя, возврат после завершения и отмены. Проверены обе темы и DPI 1 / 1.5 / 2. Доказательства: [совместное скрытие](qa-grouped-toolbar-hide.md).

Для смены типа и языка ранее пройдены браузерные проверки, три Rust-теста правил клавиш и целевая нативная проверка раскладки/сохранения текста. Ограничение: дополнительный старый тест `capture_0368_native.py` нестабилен на создании закрепа через Ctrl+Alt+F7; полная регрессия системных сочетаний не заявляется. Подробности: [тип фигуры и язык](qa-shape-type-text-language.md).

В текущем шаге изменены только метаданные версии и документация. Выбор `test:changed -- --list --files` для пяти файлов версии даёт ноль поведенческих тестов; тот же список выполнен без --list. Уже пройденные поведенческие проверки не повторяются без изменений исходников.

EXE собирается Tauri CLI без `inline-qa`, с проверкой версии, встроенного frontend и идентификатора приложения. Снимок исходников создаётся от тега 0.36.13 через отдельный Git-индекс, не меняя HEAD, индекс и незавершённые изменения основной рабочей копии. Коммит содержит `[skip ci]`, чтобы Actions не заменил проверенный EXE повторной сборкой. Публикуются EXE и SHA-256; оба вложения скачиваются обратно и сверяются.

Доказательства выпуска: [qa-artifacts/release-03614](qa-artifacts/release-03614/).
