# Выпуск Snipcast 0.36.15

Дата: 29 октября 2026 года.

Релиз включает режим качества видео «Лучшее» и исправление рассыпания при резких сменах изображения. Подробные динамические проверки, ограничения и результаты сравнения кадров: [qa-video-scenes.md](qa-video-scenes.md).

Исходники выпуска подготовлены в отдельной рабочей копии от тега 0.36.14. Включены только девять файлов реализации/проверок видео из этой задачи, пять файлов версии и относящаяся к видео документация. Все девять файлов побайтово совпадают с проверенными исходниками; остальные незавершённые изменения основной рабочей копии не включаются. [Сверка исходников](qa-artifacts/release-03615/source-verification.json).

В шаге выпуска изменены только версия и документация. Для пяти файлов версии просмотрен выбор `npm run test:changed -- --list --files`, затем выполнена та же команда без `--list`: поведенческих проверок не выбрано. Уже пройденные проверки неизменённой реализации повторно не запускаются.

EXE собирается через `npm run tauri build -- --no-bundle`. Перед публикацией проверяются версия 0.36.15, встроенный frontend, стандартный идентификатор приложения и отсутствие QA-конфигурации. Публикуются только портативный EXE и SHA-256; после загрузки оба вложения скачиваются обратно и сверяются.

Коммит тега содержит `[skip ci]`, чтобы workflow выпуска не заменил проверенную локальную сборку другой. HEAD и индекс основной рабочей копии сохраняются.
