# Подсказки: значения по умолчанию и разделитель

14 октября 2026. Изменения по двум снимкам пользователя.

Новая конфигурация получает: подсказки включены, режим «Постоянно»,
поиск по тексту выключен, порог 3 символа, текстовый триггер `=`,
переключение по `F9`, пустой список исключений. Значения синхронизированы
в TypeScript и Rust. Уже сохранённые параметры сохраняются при обновлении.
Разделительная линия над блоком убрана в обеих темах.

Выбор проверок сделан через `test:changed --list --focus text-suggestions --files`
только по файлам текущей задачи, затем запущен тот же выбор без `--list`.
Headless UI проверяет новую конфигурацию без `textSuggestions`, каждое значение
и отсутствие границы; прежние сценарии сохранения и формы также проверяются.
Rust проверяет значения новой конфигурации и сохранение явно заданных старых
параметров. Интерактивный ввод на рабочем столе не использовался.

Компактные подтверждения: [qa-artifacts/suggestions-defaults](qa-artifacts/suggestions-defaults/).
Снимки новой конфигурации — `defaults-dark.png` и `defaults-light.png`.
Проверки — `tests.log`; сборка и текущий EXE — `build.json`, `running-release.json`.

Семь Rust-тестов и headless-проверки прошли. Производственная сборка 0.36.11
без `inline-qa` установлена и запущена из `dist-release/snipcast.exe`.
Предыдущий экземпляр завершён обычным `WM_QUIT` после проверки отсутствия
открытых рабочих окон записи/редактора. Путь, версия и SHA-256 проверены.

`cargo clean` удалил 4 827 файлов (2.1 GiB) из target этой задачи.
Также удалены временные результаты UI, `dist` и локальный кэш Vite.
Освобождено около 2.14 GiB. В `dist-release` только актуальный EXE и его
контрольная сумма; сведения об очистке — `cleanup.json`, `cleanup.log`.
