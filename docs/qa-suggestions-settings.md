# Настройки подсказок: тумблер и компактные строки

14 октября 2026. Изменения по шести снимкам пользователя.

- Общий тумблер «Подсказки во время ввода» скрывает параметры при выключении.
  Режим, поиск по тексту, порог, триггер и исключения сохраняются.
- Остались два режима: «По триггеру» и «Постоянно». Кнопка «Выключены»
  и описание клавиш под режимами удалены.
- Описание поиска отделено от следующего параметра. Количество символов
  и текстовый триггер расположены рядом со своими подписями; поле количества
  имеет ширину 72 px. Пояснение под количеством удалено.
- «Вызов подсказок» удалён из UI, конфигурации, регистрации Windows и обработки
  ввода. Старое поле `activationHotkey` игнорируется при чтении и не сохраняется.
  Клавиша включения/отключения (`Ctrl+Alt+T` по умолчанию) сохранена.
- Старый пустой триггер при включении режима по триггеру заменяется на `/`.

## Сборка и очистка

Производственная сборка 0.36.11 без `inline-qa` установлена в
`dist-release/snipcast.exe` и запущена. Путь, версия и SHA-256 проверены;
текущий процесс — 142624. Предыдущий экземпляр завершён обычным `WM_QUIT`
после проверки скрытых рабочих окон и отсутствия записи/редактора.

`cargo clean` удалил 4 827 файлов (2.1 GiB) из изолированного target задачи.
Временные результаты UI, каталог сборки и локальный кэш Vite удалены;
освобождено около 2.14 GiB. В `dist-release` остались только актуальный EXE
и его контрольная сумма. Подробности — в `cleanup.json` и `cleanup.log`.
