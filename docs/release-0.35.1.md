# Snipcast 0.35.1

- Контекстные подсказки содержат горячие клавиши и уходят в свободный угол при приближении курсора.
- Клавиши показаны под названиями кнопок. Инструменты и действия распознавания доступны на 1–8 и нумпаде.
- Пробел закрепляет область; A выбирает монитор под курсором и сохраняет аннотации.
- Свободное рисование сглаживается. Прямой участок, созданный с Shift, сохраняется при продолжении штриха.
- Размер текста показан в процентах от ширины области. Добавлены включение обводки, её цвет и толщина.
- Для размещения фигур и текста используется перекрестие; «Готово» обозначено галочкой.
- Редактор закрепа восстанавливает геометрию через backend, сохраняет положение и масштаб снимка, отбрасывает запросы завершённых сеансов и удаляет нативную рамку Windows.
- Геометрия подсказок кешируется; панели редактора измеряются без изменения окна во время жеста.

Исполняемый файл собран из текущего рабочего дерева с сохранёнными незакоммиченными изменениями. GitHub Release в этом этапе не публиковался.

Проверки и ограничения: [qa-0.35.1.md](qa-0.35.1.md).
