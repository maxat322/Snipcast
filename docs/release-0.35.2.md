# Snipcast 0.35.2

- Подсказки после выделения стали компактнее: одна строка «1 2 ... 8 — выбрать инструмент», убраны описания перемещения и маркеров. Повтор действия доступен через Ctrl+Shift+Z; Ctrl+Y убран, включая ввод текста.
- Исправлена запись повторяющихся точек свободного рисования, мешавшая сглаживанию кривых. Края штриха сглаживаются через увеличенный буфер его границ; предпросмотр и PNG используют одну отрисовку.
- Колесо меняет размер текста до размещения, при редактировании и для выбранной надписи. Курсор ввода и текст сохраняются.
- Esc работает после переключателя «Обводка» и ползунков параметров.
- Закреп сохраняет режим окна без системной шапки при повторном показе, масштабировании и открытии редактора: повторное добавление стилей рамки блокируется до их применения Windows.
- Для теней панелей редактора расширена прозрачная область окна. Содержимое кнопок тулбара выровнено сверху.
- В меню закрепа добавлены иконки. В меню трея появился пункт «Закрыть все закрепы».

Сборка содержит текущие незакоммиченные изменения рабочего дерева. Проверки и ограничения: [qa-0.35.2.md](qa-0.35.2.md).
