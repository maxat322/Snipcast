# Snipcast 0.35.3

- Свободное рисование сглаживает саму траекторию во время жеста: равномерные точки через 4 CSS px, фильтр Гаусса с радиусом 3 и σ=1,5, затем кубический B-сплайн с закреплёнными концами. Исходные точки сохраняются, начало и текущий конец совпадают с указателем. Таймеров и задержки накопления нет.
- Предпросмотр, PNG, попадание мыши и границы аннотации используют общую геометрию. Отпускание мыши не меняет показанную форму. Прямой участок Shift исключён из фильтрации; продолжение сглаживается от его конца.
- Устранена системная полоса закрепа. Окно сохраняет `WS_POPUP`, занимает всю клиентскую область и блокирует системную отрисовку рамки. Фокус, выбор, прозрачность и сеансы редактора сохранены.
- В дополнительной пересборке исправлен контраст иконок выбора фигур в светлой теме: обычные контуры тёмные, выбранная фигура и наведение выделяются синим. Исправление действует в захвате и редакторе закрепа.
- В следующей пересборке устранено промежуточное растяжение и смещение закрепа при открытии/закрытии аннотирования и появлении параметров инструмента. Проверка сравнивает промежуточные кадры рабочего стола; [отчёт](qa-pin-transitions.md).
- Удалены диагональные полосы загрузки при создании закрепа. Закреп показывается после готовности PNG, сразу с изображением.
- Проверка закрепа сравнивает полные снимки рабочего стола с ожидаемой композицией изображения, прозрачного фона, тени и панелей. Прежние проверки только стилей и нескольких верхних рядов пикселей не обнаруживали воспроизведённую полосу.

Проверки, артефакты и ограничения: [qa-0.35.3.md](qa-0.35.3.md). Сборка включает существующие незакоммиченные изменения.
