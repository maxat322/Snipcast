# Snipcast 0.36.11

## Быстрая палитра во время ввода

- Шаблоны предлагаются при наборе текущего слова. Доступны два режима:
  **«Постоянно»** и **«По триггеру»**.
- По умолчанию подсказки включены постоянно: **3 символа**, триггер **`=`**,
  включение/отключение по **F9**. Поиск по тексту выключен, список исключений пуст.
  Все параметры редактируются; сохранённые настройки остаются прежними.
- Поиск идёт по названиям; переключатель **«Поиск тексту»** добавляет содержимое
  шаблонов. Плашка показывает до пяти вариантов, первый выбран сразу.
- **↑/↓** выбирают вариант, **Enter** заменяет набранный фрагмент вместе с
  триггером. **Esc** закрывает подсказки, сохраняя текст; пробел завершает поиск.
- Быстрая палитра сохраняет положение после появления. Если каретка недоступна,
  окно располагается по центру рабочей области монитора исходного приложения.
- Поля шаблона заполняются внутри быстрой палитры. До подтверждения исходный
  текст сохраняется. Большие формы используют страницы без полосы прокрутки;
  введённые значения сохраняются при переходах. Вложения подтверждаются отдельно.
- Общий тумблер скрывает параметры при выключении. Поля настроек стали компактнее;
  отдельная горячая клавиша вызова подсказок и лишние пояснения удалены.

## Группы шаблонов

- Группы во вкладке **«Шаблоны»** можно переставлять мышью. Маркер показывает
  место вставки; длинный список прокручивается у края.
- **Esc**, потеря фокуса или отпускание вне списка отменяют перенос.
  Выбранная группа, шаблоны, цвета и мастер-файлы сохраняются.
- Автосохранение и изменение порядка выполняются последовательно, чтобы
  запоздавший ответ не заменял более новую правку.

## Загрузка и проверка

Портативная версия для Windows: скачайте **snipcast.exe** и запустите.
Размер — **18 172 928 байт** (около 17,33 МиБ).
Контрольная сумма опубликована в **snipcast.exe.sha256**.

SHA-256: `19bdbcbf8f8fe3a91abb209cc1d2afc2ec6d7a9a089f6a7963ac419912800d42`.

Производственная сборка выполнена через Tauri CLI без тестового режима ввода.
Проверены поиск и настройки в Rust, Windows-логика и скрытые HWND без смены
фокуса, интерфейс в обеих темах, заполнение полей и перетаскивание групп.
Отчёты: [настройки и значения по умолчанию](https://github.com/maxat322/Snipcast/blob/0.36.11/docs/qa-suggestions-defaults.md),
[форма и замена](https://github.com/maxat322/Snipcast/blob/0.36.11/docs/qa-quick-palette-fixes.md),
[группы шаблонов](https://github.com/maxat322/Snipcast/blob/0.36.11/docs/qa-0.36.11-template-groups.md).

**Ограничения проверки:** окончательная нативная приёмка новой формы и замены
в MAX, Notepad++, терминалах и совместной работы с переключателями раскладки
не завершена. Подсказки доступны в Windows; парольные поля и повышенные окна
исключены, UIAccess не включён. Ранние проверки Win32/Chrome описаны отдельно
и не подтверждают совместимость последнего механизма замены во всех приложениях.
