# Snipcast 0.36.12

## Исправлена подстановка через быструю палитру

- Исправлены случаи, когда рядом с шаблоном оставалась набранная команда
  или вставка не выполнялась из-за проверки выделения и каретки Windows UI Automation.
- Перед заменой проверяется целое слово вместе с триггером, чтобы не оставить
  начало команды при быстром наборе.
- В редакторах без нативного адаптера команда выделяется клавиатурой;
  проверяются фактически выделенный текст и свежий результат вырезания.
  Шаблон вставляется после успешного вырезания. Устаревшее UIA-выделение
  больше не блокирует подстановку.
- В стандартных полях Windows и Notepad++ используются нативные операции
  удаления и вставки с проверкой границ и состояния текста.
- Исправление действует для обычных шаблонов, форм заполнения и вложений.
  Проверки смены окна, поля и ввода сохранены; после частичного выполнения
  замена автоматически не повторяется.

Воспроизведённая пользователем блокировка устранена: повторная проверка
подтвердила вставку шаблона и удаление команды. Автоматически проверены
16 сценариев, включая 60 замен через отдельный рабочий стол и собственный
буфер обмена Windows, без переключения фокуса пользователя.

Скачайте портативную версию **snipcast.exe**. Контрольная сумма доступна
в **snipcast.exe.sha256**. Пользовательские настройки и шаблоны сохраняются.

Полная проверка всех сторонних редакторов, терминалов и переключателей
раскладки не проводилась. Редакторы с нестандартными Copy/Cut требуют
отдельной проверки. Парольные поля и повышенные окна исключены; UIAccess
не включён.
