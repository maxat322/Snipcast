# Snipcast 0.36.14

- При рисовании и изменении фигур основная панель и настройки цвета, прозрачности и толщины скрываются вместе, если курсор попадает на любую из них. Это работает и в редакторе закрепа. После выхода курсора или завершения действия панели возвращаются.
- Нажатие другой формы в панели «Фигура» меняет тип выбранного объекта. Доступны отмена и повтор.
- Исправлено определение раскладки Windows при вводе текста на снимке. Временная потеря фокуса при системном переключении языка сохраняет текст и положение курсора.

Портативная версия для Windows: скачайте `snipcast.exe`. Файл `snipcast.exe.sha256` содержит контрольную сумму.
