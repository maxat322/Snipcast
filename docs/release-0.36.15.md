# Snipcast 0.36.15

- Добавлен режим качества видео «Лучшее»: при сохранении MP4 приоритет отдаётся деталям изображения.
- Повышено качество исходной записи, чтобы детали сохранялись ещё до экспорта.
- Исправлено рассыпание изображения при резких сменах сцены в режиме «Лучшее».

В режиме «Лучшее» размер файла зависит от сложности видео и может быть больше, чем в остальных режимах.

Портативная версия для Windows: скачайте `snipcast.exe`. Файл `snipcast.exe.sha256` содержит контрольную сумму.
