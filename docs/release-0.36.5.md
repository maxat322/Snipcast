# Snipcast 0.36.5

## Запись экрана и редактор видео

- Запись выбранной области экрана через WCAP. Кнопка «Видео» находится перед
  «Сохранить» на панели захвата; горячая клавиша — **V**.
- Компактная панель записи внизу по центру экрана: **F11** — пауза/продолжить,
  **F12** — завершить запись.
- Отдельное окно редактора с предпросмотром, кнопкой «Плей/Пауза», перемоткой
  зажатой ЛКМ и обрезкой начала/конца записи.
- При перетягивании границы показывается её текущий кадр. Курсор
  воспроизведения скрывается на время перетягивания и после отпускания
  появляется в прежней позиции.
- Обрезка кадра с подтверждением «Применить обрезку», отменой и сбросом.
- Сохранение в **MP4** или **GIF**. Для MP4 доступны настройки качества;
  для GIF — ширина и частота кадров.
- Удержание «Сохранить» открывает быстрые папки из настроек скриншотов.
  Успешное сохранение закрывает редактор.

## Исправления и скриншоты

- Исправлены повреждённые MP4/GIF при экспорте области с шириной, не кратной 16.
- Выпадающие списки соответствуют теме приложения. Исправлены углы окна
  редактора и панели записи, курсоры изменения размера обрезки.
- Компактные ручки таймлайна: синяя рамка заканчивается между ними.
- Сохранение аннотированного снимка в файл; **C** — копирование изображения
  в буфер обмена.

## Сборка и проверка

Портативная версия Windows: скачайте `snipcast.exe` и запустите его.
Размер EXE — **17 433 088 байт** (около 16,63 МиБ).
Контрольная сумма находится в `snipcast.exe.sha256`.

Проверены настоящая запись области, обе ручки таймлайна с мышью Windows,
предпросмотр и продолжение воспроизведения, MP4/AAC/GIF, обрезка кадра,
сохранение/отмена/быстрые папки, обе темы и глобальные F11/F12.
Нативная проверка выполнена на Windows 11 с масштабом 100%.
