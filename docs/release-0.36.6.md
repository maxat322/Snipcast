# Snipcast 0.36.6

- Центральные направляющие по Alt с сохранением внутри выделения.
- Настраиваемые клавиши сохранения, закрепления и копирования в «Основных».
- История 30 снимков между запусками: «−»/«+», NumPad, восстановление области и возврат к текущей правке.
- Стандартный полноэкранный пресет Alt+PrintScreen на системный рабочий стол.
- Расширенная палитра, компактная панель без заголовка под выбранным инструментом, Shift при редактировании фигур.
- Быстрые папки по наведению на «Сохранить», включая аннотации и видео.
- Убрана мешающая подсказка закрепа. Исправлены повторное преобразование цвета через ICC и дробное масштабирование PNG.
- Проверки выбираются по изменённым файлам; интерфейс видео проверяется коротко без записи и кодирования.

Локальный портативный EXE: 17 680 384 байта, SHA-256 рядом с ним в `dist-release/`. Новый релиз GitHub не опубликован.
